# Smart Parking Slot Management System

## Overview
The *Smart Parking Slot Management System* is a console-based Java application that simulates a real-world parking management system.  
It allows users to *park vehicles, exit vehicles, calculate parking charges, generate tickets, and view parking status*.  
The system supports multiple vehicle types including *BIKE, CAR, SUV, and EV*, with dedicated slot types.

---

## Features
- *Menu-driven console application*
- *Vehicle entry and exit tracking* with real-time timestamps
- *Automatic slot allocation* based on vehicle type
- *Dynamic parking fee calculation*
- *Parking ticket generation*
- *Search vehicles by number*
- *View parking lot status* (occupied/available slots)
- *File handling* to save and load parking data
- *Transaction logging* for all exited vehicles
- *Extensible design* using Java OOP, enums, and utility classes
